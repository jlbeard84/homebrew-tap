# Jlbeard84 Tap

## How do I install these formulae?

`brew install jlbeard84/tap/<formula>`

Or `brew tap jlbeard84/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "jlbeard84/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
